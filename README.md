## 📝 Project Description

The Restaurant Menu Page is a simple and attractive digital menu
card developed using HTML, CSS, and JavaScript.

It displays different food items in categorized sections, along with
their descriptions, prices, and images. Users can filter menu items
by category and add items to their order using interactive buttons.

The main objective of this project is to learn the fundamentals of
web development, including webpage structure, styling, Flexbox layout,
DOM manipulation, and JavaScript event handling.

## 🎯 Project Objectives

- Create an attractive and user-friendly restaurant menu.
- Display food items with names, descriptions, prices, and images.
- Organize menu items into different categories.
- Implement category filter buttons using JavaScript.
- Add an interactive "Add to Order" feature.
- Practice HTML, CSS, and basic JavaScript.

## ✨ Features Implemented

- *Categorized Menu:* Separate sections for Starters, Main Course,
  Desserts, and Beverages.
- *Food Images:* Display images of different dishes.
- *Food Descriptions:* Show a short description of each food item.
- *Price Display:* Display the price of every menu item.
- *Category Filters:* Filter menu items by category using buttons.
- *Add to Order:* Allow users to add items to their order.
- *Item Counter:* Display the number of items added to the order.
- *Hover Effects:* Highlight food item prices when hovering over
  menu items.
- *Responsive Layout:* Organize menu items neatly on different
  screen sizes.

## 🛠️ Technologies Used

### 1. HTML5
- Creates the structure of the restaurant menu page.
- Organizes menu categories and food items.
- Displays images, descriptions, and prices.

### 2. CSS3
- Styles the webpage using an elegant food-themed color palette.
- Uses Flexbox to arrange menu categories and food cards.
- Adds hover effects and visual improvements.
- Helps make the layout responsive.

### 3. JavaScript
- Implements category filter buttons.
- Shows or hides menu items based on the selected category.
- Updates the order counter when an item is added.
- Handles button clicks and other interactive features.

## 🚀 How to Run the Project

Follow these steps to run the Restaurant Menu Page:

1. Download or clone the project repository.
2. Open the project folder on your computer.
3. Make sure index.html, style.css, and script.js are present.
4. Ensure that the image paths in the HTML file are correct.
5. Double-click index.html to open it in a web browser.
6. Explore the menu categories and test the filter buttons.
7. Click the "Add to Order" buttons to test the item counter.

*Requirements:* A modern web browser such as Google Chrome,
Microsoft Edge, or Mozilla Firefox

No additional frameworks or libraries are required.
